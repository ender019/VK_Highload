# Яндекс Диск

## 1. Тема

Яндекс Диск — облачное файловое хранилище, интегрированное с экосистемой сервисов. Ключевым функционалом является надежное и доступное с любых устройств хранение пользовательских данных, их синхронизация и возможность совместной работы с файлами.

## 2. Целевая аудитория

*   **География:** Россия и страны СНГ (основной регион присутствия сервисов Яндекса). Доступ к сервису есть из любой точки мира, однако подавляющая часть активной аудитории находится в этом регионе.
*   **Инфраструктура:** Распределенная сеть дата-центров Яндекса на территории России для обеспечения отказоустойчивости, скорости доступа (низкой задержки) и соблюдения требований к локализации данных. Количество дата-центров исчисляется единицами, но каждый из них представляет собой гигантское хранилище данных.
*   **Активность (оценка):**
    *   **Месячная активная аудитория (MAU):** 30-40 млн пользователей.
    *   **Дневная активная аудитория (DAU):** 8-12 млн пользователей.
    *   **Количество сохраняемых файлов в день:** 1+ млн.
    *   **Общий объем хранимых данных:** 10+ Пб.

## 3. Ключевой функционал

1.  **Загрузка, хранение и скачивание файлов:** Поддержка файлов любых типов и размеров (с ограничениями для бесплатных аккаунтов), доступ через веб-интерфейс, десктопные и мобильные приложения.
2.  **Синхронизация файлов между устройствами:** Автоматическое обновление версий файлов на компьютере, телефоне и в облаке при подключении к сети.
3.  **Автоматическая загрузка фото и видео с мобильных устройств:** Фоновый процесс для резервного копирования медиафайлов.
4.  **Общий доступ к файлам и папкам:** Генерация публичных ссылок с настройками прав (только просмотр или редактирование), приглашение конкретных пользователей.
5.  **Работа с документами онлайн:** Встроенные офисные редакторы (текстовые документы, таблицы, презентации) для просмотра и совместного редактирования без установки ПО.
6.  **Поиск по файлам:** Индексация содержимого и названий файлов для быстрого поиска.
7.  **История версий и работа с Корзиной:** Возможность восстановить предыдущие версии файлов или удаленные данные в течение определенного срока.

## 4. Ключевые продуктовые решения

1.  **Дедупликация данных на стороне сервера.** Техническое решение, при котором файл, идентичный уже загруженному другим пользователем, физически сохраняется только один раз. Это позволяет колоссально экономить дисковое пространство и оптимизировать стоимость хранения для миллионов пользователей.
2.  **Дифференциальная синхронизация (блочная загрузка).** При изменении большого файла (например, видеомонтажа) приложение загружает в облако не весь файл целиком, а только измененные блоки. Это критически ускоряет синхронизацию и снижает нагрузку на каналы связи пользователя и серверы.
3.  **Кэширование и "ленивая" загрузка контента для превью.** Для обеспечения быстрой и плавной работы галерей фото и видео на всех устройствах используется интеллектуальная система создания и кэширования превью (миниатюр) разного размера. Полная версия файла загружается только по запросу пользователя, что экономит трафик и ускоряет интерфейс.
